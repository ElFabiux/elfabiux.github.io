# Personal Portfolio

Minimal terminal-inspired personal portfolio built with HTML, CSS, and JavaScript.

## Features

- Responsive dark and light themes
- Projects, education, experience, and certifications
- Content managed through public Google Sheets CSV files
- Static deployment with GitHub Pages

## Run locally

```powershell
python -m http.server 4321 --bind 127.0.0.1
```

Open `http://127.0.0.1:4321` and that's all!!
